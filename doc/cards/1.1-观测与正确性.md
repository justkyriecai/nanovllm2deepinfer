# 卡片 1.1：观测与正确性

## 要记住的 why

1. **CPU 计时量不到 GPU 时间，要用 CUDA event。** CUDA 是异步的，`run_model` 发射完就返回（decode 约 0.6 ms），GPU 的真实耗时全部落在第一个同步点 `.tolist()` 上（约 72 ms）。
   - 不这样做：用 `perf_counter` 包住前向，会得出「前向只要 0.6 ms」的错误结论。
   - 代价：event 要等 GPU 跑过才能读，读数必须放在同步点之后。

2. **不新增同步点，复用 `.tolist()`。** event 在 `.tolist()` 之前 record、之后读。
   - 不这样做：中间插 `torch.cuda.synchronize()`，GPU 在前向和采样之间多出一段 bubble，测量改变了被测对象；以后做 ZOS（CPU/GPU 重叠）时会直接把重叠打掉。
   - 代价：只能在已有同步点的地方读数。DeepInfer 在 ZOS 下没有每步同步点，所以用 `query()` 非阻塞读，读不到就留到下次（`deepinfer/timer.py:264`）。

3. **event 量的是跨度，不是忙碌。** 两个书签之间 GPU 空等 CPU 的间隙也算进去。
   - 不这样做（盲信 `gpu_busy`）：prefill 走 eager，发射约 60 ms 是固定成本，小 prefill 步其实是 launch-bound，`gpu_busy` 却显示 98%。
   - 代价：要看真实空隙得上 kernel 级时间线（`bench/timeline.py` + Perfetto，或 nsys）。判断读法：`cpu_launch ≈ gpu_forward` 且 `cpu_sample_wait ≈ 0` → launch-bound。

4. **到达时间按步定义，不按墙钟。**
   - 不这样做：GPU 快慢一抖动，请求就落在不同的步，调度决策变了，before/after 没法比。
   - 代价：TTFT 从 `add_request` 的墙钟算起，不含虚拟等待；按步到达不等于真实在线流量。

5. **warmup 要覆盖真实负载的形状，包括 batch=1。** torch.compile 遇到新形状会当场重编译（约 1 s），batch=1 被单独特化。
   - 不这样做：编译时间混进测量，prefill 的 max / p99、`gpu_sample` 被污染（实测 1.3 s 尖峰）。
   - 代价：每次跑场景多十几秒 warmup。实测补上 batch=1 的 warmup 后，prefill 的 `gpu_sample` max 从 1300 ms 降到 0.4 ms，`wall` max 从 1366 ms 降到 448 ms。

6. **正确性要一把外部的尺子，而且要按均值判、带容差。** HF 当裁判：`greedy_match`（前缀长度）+ `nll`（teacher-forced）。
   - 不这样做：改坏一行（prefill `causal=False`），吞吐一个数都不变，没人知道引擎在说胡话。
   - 代价：bf16 下 logits 会平局，单个 prompt 的 `greedy_match` 会从 32 掉到 0，所以只能按 8 个 prompt 的均值判；nano 采样不带 seed，每次基线略有不同。要逐位相等得等 2.12 的 batch invariant（见 issue #8）。

## 可以忘的细节

| 细节 | 位置 |
|---|---|
| 3 个 event 复用，在 `warmup_model()` 之前创建 | `model_runner.py` `__init__` |

## L4 + Qwen3-0.6B 实测

| 场景 | 吞吐 tok/s | decode gpu busy | 抢占 | 说明 |
|---|---|---|---|---|
| steady_decode | 1770 | 98.8% | 135 次 / 47 请求 | L4 上 KV 只够约 16 万 token，也会抢占 |
| mixed_long_short | 2436 | 97.7% | 0 | TBT p99 141 ms vs p50 46 ms：长 prompt 插进来卡住 decode（→ 2.2） |
| kv_pressure | 1593 | 98.0% | 451 次 / 266 请求 | TTFT p50 达 88 s（→ 2.3） |
| many_small | 11654 | 89.7% | 0 | gpu busy 最低，CPU 开销占比开始冒头（→ 2.5） |

破坏实验（prefill `causal=False`）：`greedy_match` 均值 24.8 → 0，`nll` 0.565 → 1.086，`--golden` 报 2 个 failure、退出码 1。
